## 2. 音響

体育館の放送機材は2種類あります。

| | 放送室（舞台横のスピーカー） | ポータブルスピーカー |
|---|---|---|
| 台数 | 1系統 | 2台（1台がメイン） |
| マイク | 2本 | 2本 |
| 入力 | CD、音楽用の大きめのジャック、インプット端子 | タブレットを直接つなげる。CDも入る |
| 特徴 | 音楽向きかもしれない。操作する人が別に要る | 声（マイク）向きかもしれない。その場で操作できる |

- 試したところ、放送室側は反響してあまりうまく聞こえず、ポータブルの方がマイクが通った
- 「声はポータブル、音楽は放送室」のように組み合わせる案も出た。音の響き方を見て臨機応変に決める
- ポータブルにはオプションのBluetoothユニットが付いているが、起動のさせ方が分からない
- 先方の機器にイヤホンジャックがない場合、Bluetoothでつなぐしかない
- 機種や使い方の詳細は、下見写真の一覧（`20261013_体育館下見写真/00_写真一覧.md`）にまとめた。ポータブルは UNI-PEX WA-372CD
- 140人がジャンプするとピアノの音が消えるかもしれない、という心配が出た。ピアノは蓋を開ければ結構響く、という意見もあった
