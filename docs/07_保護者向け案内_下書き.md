## この版での変更点（9/21の推敲内容を反映）

1. **「内容を一新した理由」の表現変更**：「今年度は新たに内容を一新し」の前に
   「先生方のご要望のもと」を追加。PTA側が独自判断で変えたのではなく、学校側の意向だと
   伝わるようにし、兄姉が在学中の保護者からの「なぜ変えたのか」という疑問を避ける狙い。
2. **重複文の削除**：「（これまで他学年では、音楽鑑賞や伝統芸能の体験教室などを行ってまいり
   ました）」の一文、および内容欄と重複していた「国立音楽大学の井上恵理先生（リトミック専門）
   と学生の皆さまのご指導のもと」の前置きを削除し、全体をスッキリさせた。
3. **挨拶文と内容欄の統合**：「国立音楽大学の井上恵理先生と学生の皆さまをお迎えし…」の一文に
   前段の趣旨説明と後段の体験内容説明をまとめ、情報の重複を解消。
4. **持ち物欄に名札の色を明記**：「保護者名札」→「保護者名札（オレンジの名札）」。
5. **連絡事項の整理**：項目の順序を調整し、「体調がすぐれない場合」を後方に配置。
6. 小倉さんの案では一部項目に「◎」マークが付いていた（1枚に収まらない場合に削る候補という
   位置づけ）が、全体の分量的に1枚に収まるため、最終版では通常の「・」に統一した。
