## この版での変更点（9/21 ver2 → 10/2 提出版）

1. **レイアウト変更**：日付・宛先・発行者の配置を、既存の他学年お知らせの慣例
   （左上＝宛先、右上＝日付、中央＝タイトル、タイトル下に発行者を右寄せ）に合わせて
   組み直した（木下さんの指摘、9/28）。従来の「記」書き形式（縦に日付→宛先→発行者→
   タイトルと並べる形）とは異なるレイアウトになっている。
2. **「参観」を前面に出す表現に変更**：
   - 冒頭の説明文を「一緒に体験できる機会」→「**親子で体験・参観できる機会**」に変更
   - 文末を「ぜひ授業にご参加ください」→「ぜひ授業を**ご参観**ください」に変更
   - 内容欄「最後は全員で合わせます」→「最後は**子供たち**全員で合わせます」（主体が
     児童であることを明確化）
3. **持ち物欄を拡充**：「動きやすい服装でのご参加を推奨」を削除し、
   「保護者の皆さんにもその場での参加をお願いする可能性があります。服装等、予めご了承
   ください。」に変更（参観が基本だが、一部参加の余地も残す表現。10/1に吉田さんが
   チーム判断で決定した内容を反映）。
   あわせて**委員長・神澤さんの指摘で「雨天時は折りたたみ傘のご持参をお願いします
   （傘置き場がないため）」を追加**（10/1〜10/2）。
4. **連絡事項を整理**：「体験中は係の指示に従っていただき、」の一文を削除し簡潔化。
   「内容により終了時刻が前後する場合がございます。」の一文は提出版では削除されている
   （意図的な削除か確認漏れかは未確認）。
5. **結びの文を強化**：「以上」のみ→「以上、ご理解ご協力をよろしくお願いいたします。」
   （他学年の過去案内の慣例に近づけた）。
6. **AIイラストを追加**（小倉さん作成、9/30〜10/1）。手拍子をする子供たちのイラストが
   文末に入っている。

## 経緯メモ：予算承認とPTA会長確認の違い（10/1判明）

吉田さんは当初「企画書は委員長→副会長→会長の順で回付・承認が必要」と認識していたが、
10/1に神澤さんへ確認したところ、**予算承認自体は学代委員長（神澤さん）の承認のみで完結**して
いたことが判明（勘違いだった）。一方で、**保護者向け案内文に会長の名前が記載されているため、
その文書についてのみ会長本人の確認が必要**という扱いになっている。つまり：
- 予算・企画内容 → 学代委員長の承認で完了（✅ 完了済み）
- 案内文の文面 → 発行者＝会長なので、会長本人のチェックが必要（🔜 確認待ち）
という2つの異なる承認フローが存在する。
